#### Skeleton

The website follows a structured layout designed to provide a clear and intuitive user experience acriss desktop, tablet, and mobile devices. Each page is built using a consisten framework that ensures maintainability, responsiveness, and visual coherence throughout the website.

Responsive Layout

The website is designed using a mobile-first approach and adapts seamlessly to different scree sizes:

* Desktop (1200px and above):
  * Multi-column layouts
  * Full navigation menu displayed
  * Maximum content visibility and spacing

* Tablet (768px - 1199px):
  * Flexible grid layouts
  * Optiomised spacing and typography
  * Adjusted navigation for touch interactions

* Mobile (767px and below):
  * Single grid layouts
  * Collapsible navigation menu
  * Responsive images and scalable content
  * Touch-friendly buttons and interactive elements.

Key Components 

* Header: Contains branding, logo and navigation links.
* Navigation: Provides access to all primary pages and section.
* Main Content: Displays the core informaiton and services.
* Additional Sections: Includes supplementary content such as galleries.
* Footer: Provides contact information, opening times, social media links.

Design Principles

* Responsive and mobile-friendly design
* Consistent visual hierarchy
* Accessible and user-centred interface
* Maintainable and scalable code strutures

This skeleton provides the foundational framework for the website, ensuring a professional, responsive and user-friendly experience across all devices.


###### Wireframes

The Wireframes featured here are the simple versions of the wireframes illustrate the basic layout and content structure of the website across different devices. The original wireframes were created with the availability of different service sections, navigations and user flow before visual styling is applied.

Responsive Design Considerations

* Desktop: Utilises multi-column layouts to maximise screen space and improve content visibility.
* Tablet: Adapts content into flexible grid layouts with optimised spacing and touch-friendly elements.
* Mobile: Transisitions to a single-coloumn structure with a collapsible navigation menu for improved usability on smaller screens.
* Responsive Images: Images scaple proportionally to prevent overflow and maintain visual quality.
* Flexible Layouts: CSS Grid is used to ensure content adapts smoothly across different screen sizes.
* Accessiblitiy: Navigation, buttons, and interactive elements are designed to remain accessible and easy to use on all devices.
